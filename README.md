# Navero — A World of Flavours

Navero is a restaurant website I built to create a simple yet elegant online experience for a multi-cuisine restaurant. The idea was to give the website a premium look while keeping it clean, easy to navigate, and user-friendly.

The website showcases different dishes, introduces the restaurant, and provides a section for visitors to get in touch.

## What’s Inside?

- A visually appealing homepage with a hero section.
- A menu featuring dishes from different cuisines, including Indian, Italian, Japanese, and Thai.
- An About section to share the restaurant’s story.
- A contact section with restaurant details and a contact form.
- A consistent design with elegant colours and typography.
- A responsive layout for different screen sizes.

## Built With

- HTML5
- CSS3
- JavaScript

## Design

I chose a combination of charcoal, olive green, champagne gold, and ivory to give Navero a warm, elegant, and premium feel. The goal was to make the website look modern without making the design feel cluttered.

## What I Learned

While building Navero, I got to practise structuring web pages with HTML, styling layouts with CSS, and adding interactive elements with JavaScript. It also helped me understand how colours, spacing, and typography work together to create a consistent website design.

## Future Plans

Some improvements I’d like to work on next include:
- Adding table reservations.
- Making the menu interactive with cuisine filters.
- Connecting the contact form to a backend.
- Adding online food ordering functionality.
